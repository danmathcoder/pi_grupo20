# Beleza de Atendimento

Projeto front-end, criado totalmente para fins educativos para um sistema de agendamento de servicos voltado a profissionais de estetica. A aplicacao permite acessar uma tela inicial, criar um novo agendamento e consultar horarios em uma agenda com calendario.

## Funcionalidades

- Tela inicial com atalhos para novo agendamento e consulta da agenda.
- Formulario de novo agendamento com campos de nome, sobrenome, tipo de servico, data e horario.
- Consulta de agenda com calendario navegavel entre meses.
- Exibicao de horarios disponiveis e agendamentos simulados.
- Barra lateral compartilhada para navegacao entre as principais telas.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## Paginas principais

### Tela inicial

Apresenta o nome do sistema e os atalhos para as duas areas principais:

- Novo Agendamento
- Consultar Agenda

### Novo agendamento

Contem um formulario para registrar dados basicos de um atendimento:

- Nome
- Sobrenome
- Tipo do servico
- Data
- Horario

### Consulta da agenda

Mostra um calendario e uma lista visual de horarios.
